# Spiritual care in European clinical practice: interactive evidence map

Interactive companion to the scoping review:

Casucci MG, Almaraz D, Saiz Galdós J, Dekker J, de Diego-Cordero R, Rosmarin DH. *Spiritual care in European clinical practice, from recognition to routine: a scoping review.* Submitted to The Lancet Regional Health – Europe. Protocol: https://osf.io/2xaqv

The map lets readers filter and explore the 269 included publications (31 European countries, 2016 to 30 June 2026) by country, clinical domain, setting, design, level of integration, care component, and barriers and facilitators reported as study findings. All records come from the charting workbook (Supplementary File S3).

The page is a single self-contained file (`index.html`) and needs no server.
